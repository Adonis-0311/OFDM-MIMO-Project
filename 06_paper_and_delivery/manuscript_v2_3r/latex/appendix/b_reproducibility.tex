\section{Data and Code Availability}

All synthetic generators, evaluation scripts, run manifests, aggregate tables, and figure builders needed to reproduce the reported results are available at \url{https://github.com/Adonis-0311/OFDM-MIMO-Project}. The repository preserves executable paths and durable result manifests for each paper-facing claim.

Paper-facing displays are generated by scripts in the manuscript workspace. The E4 benchmark adds executable grid, bounded-refinement, Torch-layer, separable forward-backward ESPRIT, and complex PARAFAC-ALS rows; its arithmetic counts are analytical proxies, and it does not assign estimator-accuracy claims to the comparator rows. The bibliography remains under active frontier expansion and metadata review.

The implementation is covered by 24 automated tests, including bounded refinement, permutation matching, controller gradients, continuous physical conversion, the Nyquist alias lock, separable ESPRIT frequency recovery, and rank-one complex PARAFAC reconstruction. Experiment commands, configurations, seeds, environment snapshots, and metrics are stored in run manifests beside each output.
