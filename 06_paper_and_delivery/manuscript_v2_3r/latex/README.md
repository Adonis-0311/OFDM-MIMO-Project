# v2.3R IEEEtran Draft Package

Build with:

```powershell
latexmk -pdf -interaction=nonstopmode -halt-on-error main.tex
```

The package uses the IEEEtran journal template and currently compiles to eight pages. It includes four paper-facing figures, a separate graphical abstract, local G2/A4 evidence, scaled trained CDL-A/C physical results, the zero-shot CDL-D boundary, an executable E4 complexity table, and 42 cited references.

Remaining submission work is accepted-paper metadata polish, any matched comparator-accuracy study needed for an NMSE--complexity Pareto claim, trained DeepMIMO physical evaluation if retained in scope, and author/venue packaging. Executable ESPRIT/PARAFAC complexity rows, the main figure set, and graphical abstract are present.
