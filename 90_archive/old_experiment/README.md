# Undergraduate Prototype (Archived)

This folder is the frozen 2024-2025 undergraduate-thesis MATLAB prototype. It is **not** part of the v2.2 paper deliverable — it is kept for reference only:

- Earlier `Config/`, `Modules/`, `Libraries/`, `Data/` from the undergrad pipeline.
- Historical figures (`method_comparison*.png`, `OMP_performance_comparison.png`, `复杂度对比_中文版.pdf`).
- Scratch scripts (`main.m`, `StraightPlot.m`, `TrainCAEWithAdam.m`, `untitled*.m`).

Known issues recorded in `06_paper_and_delivery/paper_notes/usable_content_inventory.md` (mismatched interfaces between `SystemParams`, `OFDM_Transceiver`, `LS_Estimator`, `ANN_Estimator`, `CS_DL_Estimator`, `PilotManager`) mean this code should be treated as material/inspiration, not a working pipeline. The v2.2 paper pipeline is being rebuilt under `03_active_modules/` and `04_experiments/`.
